# Karen Fuse

**Launch the app:** https://mckaren8089-stack.github.io/karen-fuse/

**Language / زبان:** [فارسی](README.fa.md) | [English](README.en.md)

Karen Fuse is a Persian-language web app for exploring gold prices, the Iranian dollar market, and the global gold ounce price.

## Available features
- Aggregation and comparison of public gold and currency price sources
- Interactive charts and historical price trends
- Source quality and data freshness indicators where supported
- Manual Blu buy/sell quote tracking and related calculations
- Estimated gold buy/sell calculator
- Installable progressive web app (PWA) on supported devices

## Planned improvements
- More reliable collection and assessment of market data
- Refinements to chart usability, calculations, and release testing

**Note:** Market data may be delayed; prices are not guaranteed real time and are not financial advice. Manually entered data remains in the local browser.
