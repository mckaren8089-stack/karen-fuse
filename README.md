# Karen Fuse — V0.2

وب‌اپ/PWA فارسی برای پایش چندمنبعی طلای ۱۸ عیار و دلار آزاد، ثبت نمونه‌های واقعی قیمت Blu و یادگیری اختلاف Blu با قیمت مرجع بازار.

## وضعیت V0.2

- **TGJU**: طلای ۱۸ عیار + دلار؛ در اجرای واقعی GitHub Actions تأیید شده و فعال است.
- **اتحادیه طلا و جواهر تهران (ESTJT)**: طلای ۱۸ عیار؛ در اجرای واقعی تأیید شده و فعال است.
- **منابع آزمایشی عمومی**: نوسان و چند صفحه عمومی دیگر نیز بررسی می‌شوند، اما فقط منبعی که در همان اجرا داده معتبر بدهد وارد اجماع می‌شود؛ منبع خطادار عدد جعلی یا قدیمی وارد نمی‌کند.
- **Blu**: API عمومی قابل اتکا هنوز وارد نشده؛ قیمت خرید/فروش هنگام مشاهده واقعی به‌صورت دستی ثبت و Basis با وزن بیشتر برای نمونه‌های جدید محاسبه می‌شود.
- اجماع بازار با **میانه (median)** منابع سالم ساخته می‌شود تا یک منبع پرت، مرجع را خراب نکند. وضعیت هر منبع در رابط دیده می‌شود.
- تاریخچه بازار توسط GitHub Actions هر ۳۰ دقیقه ثبت و تا حدود ۳۱ روز نگه داشته می‌شود.
- داده‌های Blu فقط در `localStorage` گوشی می‌ماند و قابلیت Export/Import دارد.

## ساختار

- `index.html`, `style.css`, `app.js`: رابط کاربری موبایل‌محور و محاسبات Blu.
- `scripts/collect_prices.py`: جمع‌آوری و نرمال‌سازی منابع بدون dependency خارجی.
- `data/latest.json`: آخرین snapshot و وضعیت هر منبع.
- `data/history.json`: تاریخچه اجماع برای نمودار.
- `.github/workflows/collect-prices.yml`: اجرای خودکار جمع‌آورنده.
- `.github/workflows/pages.yml`: انتشار PWA روی GitHub Pages.

## منطق Blu Basis

هر نمونه شامل قیمت مرجع طلای ۱۸ عیار، قیمت خرید Blu و قیمت فروش Blu است. اختلاف درصدی خرید/فروش نسبت به مرجع ذخیره می‌شود و مدل از ۲۰ نمونه آخر با وزن بیشتر برای نمونه‌های جدید استفاده می‌کند.

## حریم خصوصی

هیچ قیمت Blu یا محاسبه شخصی به سرور پروژه ارسال نمی‌شود. داده بازار عمومی در مخزن ذخیره می‌شود؛ داده Blu روی دستگاه کاربر است.
